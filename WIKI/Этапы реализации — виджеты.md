**Контрольная точка:** проверены встроенные секции параметров и связей и отдельный вызов style_analysis без дублирования.

### 3.2. Перенос настроек

  - Для каждого виджета из `card_widgets` + для каждого набора параметров с `card_side` создать слот `page_layout`: левые — `column_start=1..2`, правые — `column_start=3`

**Контрольная точка:** скрипт + лог + проверка 5 типов на копии.

### 3.3. Рендеринг по макету

- [ ] `api/src/lib/publicCard.ts`: если `layout_id` задан — строить по макету, иначе — по старому механизму

  1. Получить слоты `page_layout` с сортировкой по `sort_order`

  4. **Видимый слот 2×2 сохраняет обе занятые строки** (даже если справа пусто)
  5. В гостевом выводе убрать полностью освободившиеся строки и перенумеровать остальные
  6. Вернуть HTML с CSS Grid
