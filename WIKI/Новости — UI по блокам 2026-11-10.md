# Новости — UI по блокам

Дата: 2026-11-10. Основание: «Давай UI разобьем по блокам. Реализуй».

Реализовано локально в коде. Выкладка на сервер, миграции, backup и push не выполнялись.

| Блок | Экраны |
|---|---|
| 1. Сбор | Результаты обхода `/robot/collect`, подключённые сайты `/robot/sites`, журнал `/robot/log` |
| 2. Классификатор | Результаты оценки выбранного прогона, совпадения и основания, промпт, обучение `/robot/classify` |
| 3. Редактор | Кандидаты `/robot/news`, заказ новости `/robot/orders`, стек `/robot/stack`, резонанс `/robot/resonance`, существующее превью |
| 4. Расширение источников | Проверка и решения по предлагаемым сайтам `/robot/recs` |

На `/robot` — обзор четырёх блоков. Верхнее меню сайта приведено к этой структуре. Старые адреса сохранены, права `su` сохранены. Навигация адаптирована к узкому экрану. Состояние служб свёрнуто; заранее переведённые тексты перенесены под кандидатов в раскрываемый раздел. Заказы доступны независимо от наличия прогонов.

Это группировка существующих возможностей и два обзорных экрана на действующем API. Полный стек исходных материалов с медиа, шесть категорий, методики по категориям, неизменяемый журнал решений и множественные категории источника не реализованы этой доработкой. На экранах сбора и классификатора обозначены соответствующие ограничения. Алгоритмы оценки, редакторских решений и публикации не изменялись.

Проверено: TypeScript без ошибок; production-сборка Vite в отдельной временной папке; Chromium с тестовыми ответами API — обзор, сбор, классификатор, кандидаты, заказы, стек, сайты, расширение источников; переход на ширине 390 px, отсутствие горизонтального переполнения обзора, обзор без прогонов и ограничение доступа без `su`. Ошибок JavaScript нет. Штатная сборка в `web/dist` первоначально остановилась из-за EPERM на `dist/fonts` в Dropbox; отдельная сборка успешна. Браузерная проверка использовала фиктивную конфигурацию Supabase и не обращалась к рабочим данным.

Далее — реализация данных и операций по [плану блоков](Новости%20—%20оценка%20реализации%20и%20план%20по%20блокам%202026-11-10.md): сырые материалы и медиа, категории/проверки, постоянная память решений, категории каналов источника. Пользовательская таблица этапов не менялась.
