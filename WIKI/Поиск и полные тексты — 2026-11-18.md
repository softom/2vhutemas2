# Многоязычный поиск и тексты без посредника — 18.11.2026

Выполняется по ТЗ. Ранее единственным способом получения текста был r.jina.ai; его HTTP 451 оставлял только сниппеты. Новый план: RU/EN/оригинальные имена, до шести коротких запросов, RU/COM Yandex, языковые Wikipedia, происхождение каждого результата.

Прямой загрузчик внутри API: публичный DNS A, запрет локальных/служебных IP и собственного сервера, соединение с проверенным IP с исходным TLS servername/Host, повторная проверка каждого redirect; не передаёт ключи, cookie и внутренние заголовки. До 4 редиректов, 3 MB ответа/распакованного содержимого, ограничение времени. Извлечение Readability и семантический HTML, Wikipedia API как дополнительный способ. PDF/JS-only/защищённые страницы не выдаются за успешно прочитанные. Сохраняются метод, язык, финальный URL, время, SHA256 текста, статус полноты/ошибка в существующих source_observations. Частичный текст и сниппет не принимаются как подтверждённая цитата. Старые тексты, UID, предложения, связи и версии сохраняются. Миграция не требуется.

Основание изменения сетевой модели: явное поручение пользователя убрать посредника и получать тексты самостоятельно. Фиксированные провайдеры остаются для поиска; произвольные страницы разрешены только через новый проверяющий загрузчик, не обычный fetch.


## Выпуск и проверка

Выложено 18.11.2026, согласовано с «UI доработка»; общий lock `/tmp/2vhutemas-code-release.lock`, сравнение исходных SHA256 до изменений. Миграций нет. Новые тексты появляются при следующем «Собрать источники»; прежние корпуса/UID/результаты сохраняются. Никаких автоматических изменений или публикации связей реальных карточек.

Проверки: Deno check, TypeScript/Vite build; 30 проверок загрузчика/языкового плана/HTTP framing; 52 интеграционные проверки в восстановленной codex_fulltext_0062. Реальный текст Arquitectura Viva (2541 символ) → один запрос LLM → 4 полученных/4 валидных предложения/0 отклонений → preview → сохранённая связь с точной цитатой и sourceRef. Все прежние snapshot в тестовой копии остались неизменными. Отдельно проверено извлечение испанской Wikipedia (33664 символа), а также сбор по 6 запросам на 3 языках с объединением одной страницы и сохранением происхождения. Реальные поисковые запросы: RU — 41 источник, COM/EN — 49; результаты обоих включают Yandex.

После рестарта: 263 регрессионные проверки, 0 сбоев, тестовые записи убраны. HTTPS отдаёт index-h8_mwr4e.js и EntityEditor-CJEPH6iZ.js; хеши отданных модулей сверены, API health и публичная закрытость черновиков проверены. После проверки нормализованы только CRLF→LF у исходников с проверкой предыдущих хешей; код не менялся.

Ограничения честно показываются в журнале источника: не все сайты разрешают загрузку, PDF и JS-only пока не извлекаются; пример Dragados завершает TLS без close_notify и отмечен ошибкой. Readability извлекает основной текст страницы, а не гарантирует полноту содержания издателя. Обрезка по лимиту 240000 символов помечается partial; такие предложения, как и сниппеты, нельзя принять через цитату. Поиск ограничен шестью запросами/100 внешними страницами; загрузка — четыре параллельных задачи. При наличии сохранённого текста повторный сбор его не заменяет. Новые npm зависимости закреплены на версиях linkedom 0.18.12 и @mozilla/readability 0.6.0.
