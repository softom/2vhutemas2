# Стилистический поиск и отбор свидетельств

Подготовлены миграция 0075 и изменения API. Словарь стилистических профилей дополнен основами названий направлений. Задание требует предлагать отсутствующие понятия с точным именем и разрешает отрицание лишь по прямому высказыванию источника. Для задания выбрана google/gemini-2.5-pro. Стартовый список для штатной инициализации библиотеки расширен на 16 понятий.

При отсутствии английского названия предусмотрены дополнительные русские запросы, при наличии автора или населённого пункта — запрос с контекстом. Анализ выбирает фрагменты по всему корпусу с пределом 4000 символов на источник, до двух параллельных частей по 30000 символов. Проверены общий лимит, точность исходных фрагментов и формирование запросов по русскому названию.

При проверке рабочей БД последняя миграция 0074, у набора 18 профилей, модель задания не задана. Применение 0075, инициализация новых записей и качество ответа на реальных объектах пока не проверены.
