# Стилистический поиск и отбор свидетельств

Подготовлены миграция 0075 и изменения API. Словарь стилистических профилей дополнен основами названий направлений. Задание требует предлагать отсутствующие понятия с точным именем и разрешает отрицание лишь по прямому высказыванию источника. Для задания выбрана google/gemini-2.5-pro. Стартовый список для штатной инициализации библиотеки расширен на 16 понятий.

При отсутствии английского названия предусмотрены дополнительные русские запросы, при наличии автора или населённого пункта — запрос с контекстом. Анализ выбирает фрагменты по всему корпусу с пределом 4000 символов на источник, до двух параллельных частей по 30000 символов. Проверены общий лимит, точность исходных фрагментов и формирование запросов по русскому названию.

При проверке рабочей БД последняя миграция 0074, у набора 18 профилей, модель задания не задана. Применение 0075, инициализация новых записей и качество ответа на реальных объектах пока не проверены.

## Выпуск DeepSeek V4 Pro

По решению пользователя установлен предел 200 000 символов, до пяти параллельных частей по 40 000. Проверены копия базы и кода backups/style-deepseek-20261122 (SHA256 и оглавления), миграции на отдельно восстановленных таблицах, проверка типов API и штатный health. На сервере подтверждены модель и оба лимита. Штатный мигратор дополнительно применил ранее пропущенные 0068–0072 при существовавшей 0074. Публичная карточка «Махорки» отвечает HTTP 200.

Серверный план по сохранённому корпусу: Александрина (3535) — 200 000 символов, 65 источников, 5 частей; «Махорка» (3451) — 123 509 символов, 49 источников, 4 части. Ранее соответственно 12 предложений без кандидатов и 8 с одним кандидатом. На момент проверки оба имеющихся токена вернули 401, новые вызовы модели ещё не запущены.

В редакторе набора добавлена кнопка «Очистить предложения LLM». Очистка сохраняет версию и удаляет рабочий результат только выбранного набора. Права edit и актуальная версия обязательны. Код проверен и выложен; действие в двух карточках пока не подтверждено.
