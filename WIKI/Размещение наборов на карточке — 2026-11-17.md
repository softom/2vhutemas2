# Размещение наборов на карточке

Принято по явному поручению пользователя 17.11.2026: у определения набора параметров появляется card_side — left (слева, в тексте) или right (справа, в колонке атрибутов). Настройка общая для всех карточек с этим набором. Существующие наборы по умолчанию справа; площадная программа сохраняет левое размещение, стилистические решения переводятся влево. Данные и результаты исследований не переписываются.

План: миграция 0061 с CHECK и default; GET/POST/PATCH API и единое окно набора; публичная карточка выбирает сторону по UID членства параметра в наборе. Если параметр входит в несколько наборов, приоритет у прикреплённого к записи, затем наследуемого от типа, затем определения набора по sort_order/id; одно значение не дублируется. Нераспределённые значения остаются справа. Таблица стилей остаётся таблицей, размещается в широкой левой колонке. Специальные итоги площадной программы сохраняются, её сторона тоже учитывает атрибут. Закрытые технические параметры не публикуются.

Проверки до выпуска: резервная копия БД/ролей/кода с проверкой восстановления, интеграционные проверки API/прав/сохранности значений/обеих сторон, типизация и сборка, браузерное размещение и настройка, smoke после выкладки. Общие файлы согласуются с сессией «UI доработка».

Настройка доступна в «Параметры → Наборы → Править». Для существующего индивидуального набора без привязки к ветви правка допускается без назначения нового типа. Изменение настройки выполняется PATCH по UID; права su и аудит существующей транзакции сохранены. Длинные ячейки слева переносятся, на мобильном прокручивается таблица, а не вся страница.
