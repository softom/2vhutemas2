# Загрузка редактора — 2026-11-11

Пользователь сообщил: при обновлении раздела 3 весь компьютер мигает окнами и не отвечает около двух минут; браузер Яндекс на Chromium. Предыдущая замена native select не устранила проблему и не считается подтверждённым исправлением причины.

На сервере 828 кандидатов. Редактор строил все строки одновременно и обновлял их при изменениях. Введена постраничная выдача по 30 строк: фильтры и счётчики охватывают весь набор, номера сквозные, при смене фильтра первая страница. Данные не удаляются.

Исправлена остановка автообновления: каждый запуск получает версию; запоздавший ответ прежнего запуска не меняет экран и не создаёт дополнительный таймер. Cleanup инвалидирует запросы при уходе или смене прогона. Ранее незавершённый запрос мог восстановить таймер после cleanup.

Проверены TypeScript, Vite и Chromium на тестовом API с 828 кандидатами: 30 строк в DOM, 1389 DOM-узлов; три загрузки 0,54 / 0,35 / 0,35 секунды; переход страницы и отправка своей причины без диалогов/ошибок JS, двойное нажатие даёт одну оценку. Системное мигание Яндекс Браузера не воспроизведено; найденные проблемы нагрузки/таймеров устранены, но причинная связь с системным зависанием пока не доказана.
