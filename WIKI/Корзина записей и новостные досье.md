# Корзина записей и статья из новостного досье

12.11.2026. Диагностика записи 3058: создана 12.11 в 16:05 МСК из досье 2379582e-a719-5d82-b3d3-919ebcf10041. Версия create содержит «Утверждён эскиз из стека сущностей», автор — учётная запись Артёма Антипова. Досье было передано роботом в 04:22 МСК с заданием разобрать сущности новости; эскиз выбрал статью 3DNews как сам предмет. Источники 3DNews, Anthropic, Meduza сохранены. Тип article входит в раздел «Проекты» (ветвь «Что»); черновики видны редакторам по действующим правам. Это не новый обход утверждения, а неверный предмет эскиза.

Решение и план реализации:
- Удаление в интерфейсе — обратимое помещение в корзину: status=archived, публикация снимается, текст/версии/связи/медиа не удаляются. Право create_delete, проверка исходной версии, аудит новой полной версией.
- Корзина доступна из каталога. По нажатию записи — восстановление в черновик. Восстановление не публикует запись. Публикация архивной записи запрещена, включая робота.
- В форме — «Удалить…» и подтверждение на странице. Несохранённые правки не записываются при удалении, что явно подписано.
- Для досье с действующим маркером задания робота «Разобрать сущности по материалам новости:» исключены типы article/news/web_page и их потомки из выбора LLM; дополнительная серверная проверка при утверждении старого эскиза. Источники остаются источниками, модель выделяет предмет из содержания. Маркер хранится в уже существующем описании; это совместимость с текущим форматом, не новая колонка происхождения. Обычные ручные досье статей не ограничены.
- Запись 3058 не удаляется агентом автоматически: пользователь получает действие удаления в редакторе. Источники и её досье сохраняются.

Проверки до выкладки: типы API/Web, сборка, API-сценарий корзины с временной записью (права, конфликт версии, сохранность текста, исключение из каталога, восстановление без публикации), штатный smoke. Миграций нет. Предыдущий код и сборка резервируются на сервере.
