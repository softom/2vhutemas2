Основание: [согласованное ТЗ](ТЗ%20—%20настройки%20исследований%20и%20единая%20форма%20наборов.md). «UI доработка» подтвердила отсутствие пересечений и отложила правки занятых компонентов до передачи результата.

## Состав

- Миграция 0063 расширяет существующие parameter_sets и parameter_set_items. Задания/языковые профили и допустимые типы/роли связаны с набором по UID. Параметры, наборы и значения сохраняют UID.
- Конфигурации получают неизменяемые снимки и автора; изменения в старых административных маршрутах также записывают версии. Запуск сохраняет версию конфигурации, UID задания и фактическую модель. Несколько заданий требуют явного выбора, не запускаются все автоматически.
- API GET/PATCH /parameter-sets/:id/config требует su; PATCH — config_version. Действующее окно набора передаёт ожидаемую версию и явные UID удаляемых вхождений. Старые частичные списки состава не стирают настройки и остальные вхождения.
- Общий ResearchProposalForm отображает обе ветви: значения и связи. Адаптеры готовят данные и операции, без собственной разметки предложений. Одинаковы выбор, массовые кнопки, Было/Будет, источник, цитата, обоснование, статус и единственная кнопка сохранения.
- Принятие параметров сохраняет рабочую версию карточки одной операцией, а не только переносит значения в форму. Связи сохраняются штатной транзакцией с повторной проверкой версий и цитат.
- Поисковые темы, инструкции и ключевые слова отбора перенесены в данные. Два вызова/60000 символов остаются жёсткими потолками, профиль может уменьшить их. Доказательства проверяются сервером; права и ключи не переносятся в параметры.
- Колонки табличного поля читают подпись, вид ввода и краткое представление из определения вхождения. Старые таблицы стилей остаются в истории, не возвращаются в интерфейс.

## Границы

Полный редактор расширенных настроек — будущий этап ТЗ; текущий административный API готовится вместе с моделью. Полноценная разная повторяемость одного параметра в разных наборах НЕ включена: сервер подтвердил отсутствие контекста set_id у группы/значения, сохраняется inherit и действующее ограничение БД. API отвергает переход к неоднозначной повторяемости, а не меняет данные молча. Отдельная кнопка старого исследования в стеке не удаляется этим выпуском: выбор варианта её замены ещё не утверждён.

Служебные параметры relation-слотов описывают вывод связи; API принятия пишет связь и цитату, не создаёт параллельные значения этих слотов у объекта. Имена заданий/наборов не являются внутренними ключами.
