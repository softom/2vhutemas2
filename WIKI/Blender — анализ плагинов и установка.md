# Blender: выбор прямой интеграции и инструментов работы по фото

Дата проверки: 2026-09-23. Статус: рекомендация, не установленное и не проверенное локально подключение. В каталоге доступных плагинов поиск Blender не вернул результатов; рассматриваются самостоятельные MCP-серверы.

Для текущей связки Windows + Blender 5.2.2 + Codex и нескольких файлов рекомендуем начать пилот с newo-ether/blender-mcp. Основания: выбор конкретного открытого экземпляра, установщик Windows, работа с узлами. Документация: https://github.com/newo-ether/blender-mcp . Релиз v1.19.0: https://github.com/newo-ether/blender-mcp/releases/tag/v1.19.0 — разработчик сообщает о тестах на 5.2.0; 5.2.2 нами не проверена. На странице релиза лежат Blender Extension ZIP, Python wheel, отдельный skill и SHA256SUMS.txt. Для Codex нужен MCP-сервер вместе с расширением Blender; MCPB предназначен для Claude Desktop.

Альтернатива: ahujasid/mcp-for-blender (ранее blender-mcp), https://github.com/ahujasid/mcp-for-blender . Прямое управление сценой, Python и экспорт, большая экосистема; заявлен Blender 3.0+. Требование версии не равно проверке на 5.2.2. Установка описана в README, аддон addon.py. Полная телеметрия отключается DISABLE_TELEMETRY=true.

Резервный кандидат: carlosh7/blender-mcp, https://github.com/carlosh7/blender-mcp . Широкий набор специализированных операций и экспортов; автор заявляет Blender 4.2+/5.x. Число инструментов не считаем доказательством качества архитектурной реконструкции. Установки: https://github.com/carlosh7/blender-mcp/releases/latest .

Для совпадения камеры с фотографией: fSpy https://fspy.io/ плюс официальный импортёр https://github.com/stuffmatic/fSpy-Blender/releases/latest . Приложение: https://github.com/stuffmatic/fSpy/releases/latest . Это вычисление камеры, не генерация здания. Совместимость импортёра с установленной 5.2.2 требует пробного импорта.

Платная альтернатива для совмещения существующей геометрии и камеры с кадром/видео: GeoTracker https://keentools.io/products/geotracker-for-blender . Не требуется для первого пилота; оценить на одном сложном случае перед покупкой.

Подключение MCP в Codex: https://developers.openai.com/codex/mcp . Плагин Blender сам по себе не добавляет инструменты в текущую задачу: требуется зарегистрированный сервер и успешное подключение клиента. Устанавливать один выбранный мост, сначала только в Blender 5.2. Рабочую область задать папкой материалов модели; открытый несохранённый файл сохранить до подключения.

Пилот при будущем поручении на установку: закрепить версию; подключиться к копии TPAC; подтвердить имя файла и экземпляр; получить viewport; изменить и отменить тестовый объект; сохранить отдельную версию; сделать рендер и экспорт GLB; затем проверить fSpy на одном кадре. Успех измерять временем итерации и совпадением контрольных ориентиров, а не количеством инструментов. Автоматическое восстановление геометрии по нескольким произвольным фото этим не гарантируется.

Установка и изменения конфигурации в рамках исследования не выполнялись. Независимые проверки заявлений авторов и полный аудит кода не проводились.
