# Национальный театр Тайчжуна — площадная программа (исследование)

Дата: 2026-10-14. Автор исследования: Claude (агент). Статус: **данных по помещениям нет; есть итоговые площади по трём источникам, они расходятся**. Запись в БД не вносилась. Объект — [Базовые сведения, ID 49](Базовые%20сведения%20зданий%20—%20сверка%202026-10-13.md).

## Цель

Площадная программа здания: залы, фойе / гардероб / холл, санузлы, технические помещения вплоть до вентиляционных камер.

Противоречия:
1. Итог разбивки (36 410) не совпадает с заявленной «floor area» (43 264): разрыв 6 854 м² страница не объясняет.
2. Метка «Other space» (16 090 м²) — самая крупная позиция, но это не назначение помещения. В ней, вероятно, фойе, гардероб, санузлы, холлы и техника. Разложить её без источника нельзя.
3. Текст страницы говорит о «комплексе 58 000 м²», а в таблице — 43 264 м² «floor area». Какая мера здесь подразумевается, не указано.
4. Метка «2009 seat» — опечатка или 2 009 мест; текст даёт 2 000.

Эту разбивку **не используем** как основу, пока нет первоисточника (проект или Национальный центр исполнительских искусств).

## Что не найдено

- Фойе 1F и 2F — **найдены** (см. таблицу выше). Гардероб, холлы как отдельные помещения — не выделены, в плане «使用範圍» не указаны.
- Остальные зоны по NPAC-планам: «空中花園» (Sky Garden), «角落沙龍» (Corner Salon), «五樓展示廳（凸凸廳）» (Tutu) — есть планы и PDF-зоны «使用範圍», площади не сверены (следующий проход).
- Санузлы — число и площадь не найдены.
- Вентиляционные камеры и технические помещения — не найдены. Ito в интервью говорит о движении воздуха в фойе, но без цифр.
- Этажность: Arup — шесть этажей; Metalocus — подвалы B1, B2, этажи 1, 2, 6. Общая этажность в тексте не указана.
- Закулисье отдельной площадью есть только у Metalocus (2 630 м²); у остальных нет.

## Разрешительная и тендерная документация (проход 2026-10-14, второй)

Запрос пользователя: конкурсная документация, ТЗ, разрешение на строительство; здание относительно свежее, нужны любые данные.

- **Конкурс 2004–2005.** Есть подтверждение: Ito выиграл международный конкурс в 2005 (городской сайт; Architectural Record пишет о 2004 Ghent Music Forum как части заявки). **Текст конкурсной документации не найден.**
- **ТЗ в репозитории** (`WIKI/Техническое задание.md`): упоминания театра только в разделе 8 (маршрут экспозиции). Площадей, помещений, разрешений нет.
- **Строительная лицензия (建造執照), использование (使用執照).** Не найдена в открытых источниках.
- **Муниципальный реестр** — путь, который работает: [Taichung City Building Permit Stub Data, data.gov.tw/dataset/108507](https://data.gov.tw/dataset/108507). Издатель — Управление городского развития Тайчжуна. Поля:建築面積, 總樓地板面積, 地上/地下層數, 工程造價, 發照日期, 起造人地址. Лицензия открытая, бесплатно. Формат JSON (файл на newdatacenter.taichung.gov.tw) и API (datacenter.taichung.gov.tw). **Не скачивалось:** нужно разрешение пользователя (файл большой, размер не проверен). Покрытие 2014–2016 не подтверждено.
- **Результат скачивания реестра (2026-10-14, разрешение пользователя дано).** Файл `permits.json` (82 КБ) в scratchpad: **всего 100 записей** — это выборка, не весь реестр. Поиск по «惠來», «歌劇», «西屯» — 0 совпадений. Записи разных лет (от 044 до 065 по ROC), большинство с нулевыми площадями. Для театра нужной записи в выборке нет. Полный реестр: API `datacenter.taichung.gov.tw` (Swagger 387360000G) — хост не резолвится из этой среды, проверить с другой сети или через портал. Скачанный файл — открытые данные города, не правится и не публикуется.
- **Муниципальный PDF «文化焦點 臺中歌劇院 隆重鉅獻»** (culture.taichung.gov.tw, 2 страницы журнала «文化臺中», № 12–15, 2016). ## Источники для следующего шага (приоритет)

1. **Национальный центр исполнительских искусств (National Performing Arts Center, NPAC)** — владелец здания; у него должны быть технические паспорта и спецификации помещений. Запрос через сайт или пресс-службу.
2. **Toyo Ito & Associates** — проектная документация, поэтажные планы, ведомости помещений. Прямой запрос к бюро или публикация в их архиве.
3. **Taichung City Government, Department of Cultural Affairs** — документы строительного разрешения (зарегистрированы в городских PDF, например [культурный отдел Тайчжуна](https://www.culture.taichung.gov.tw/media/819740/文化焦點-臺中歌劇院-隆重鉅獻.pdf)). Искать ведомости площадей через китайский запрос «臺中國家歌劇院 樓地板面積 平面圖».
4. **Журналы с публикацией планов** — Architectural Record, DETAIL (Elena Markus, 2017), Domus (2014). Проверить, есть ли в статьях поэтажные планы с подписями.
5. **Taiwan Ministry of Culture** — [moc.gov.tw](https://www.moc.gov.tw/en/information_315_77763.html), пресс-материалы 2016 с техническими данными.

Поиск по китайским и английским запросам «фойе», «санитарные узлы», «вентиляционная камера» в этом проходе не дал результатов. Их стоит повторить с названиями из паспорта здания, когда он будет найден.

## Вывод для проекта

Полной разбивки по помещениям по-прежнему нет: найдены площади двух фойе (NPAC) и вместимость залов, но не площади санузлов, гардеробов, венткамер. Официальные PDF по сцене и закулисью скачаны и ждут разбора. Надёжная итоговая площадь — **не установлена**: три значения (34 067 / 36 000 / 43 264 м²) и участок 57 685 м² относятся к разным мерам, которые источники не определяют. Для лекции «Анатомия зрелищного здания» (см. [план 2026-10-13](Лекция%20«Анатомия%20зрелищного%20здания»%20—%20план%202026-10-13.md)) можно пользоваться только сочетанием «залы + число мест» (2 014 / 800 / 200), площадь выводить после получения паспорта здания. Долей по помещениям не публикуем, пока нет первоисточника.

## Расхождение с Берлинской филармонией

Берлинский разбор ([см.](Берлинская%20филармония%20—%20площадная%20программа%20(исследование).md)) тоже не нашёл площадей по помещениям, поэтому оба объекта в типе «театр» сейчас равны по статусу: итоговые величины есть, разбивки нет. Разница в том, что у Тайчжуна есть разбивка Metalocus, а у Берлина её нет.
