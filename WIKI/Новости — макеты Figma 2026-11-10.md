# Новости — макеты Figma

По поручению пользователя перенесены четыре блока новостного UI в Figma для проработки оформления.

[Открыть файл Figma](https://www.figma.com/design/D1SK1nT2xFm2iIFYD5BI3G)

Пять редактируемых экранов: обзор, сбор, классификатор, редактор, расширение источников. Расположение слева направо: обзор → 1 → 2 → 3 → 4. Основа — интерфейс коммита 084c96b; макеты являются упрощённой рабочей композицией для обсуждения, не точной копией всех состояний работающего сайта. Примеры новостей и числовые значения демонстрационные, отмечены на макетах. Будущие возможности обозначены как следующий этап.

Использованы Golos Text, бумажная палитра из CSS сайта, локальные переменные цветов и компоненты навигации, строк и действий. 109 редактируемых текстовых слоёв и 44 экземпляра компонентов; целые экраны не вставлены изображениями. Проверены изображения композиций.

Ссылка на редактор: https://www.figma.com/design/D1SK1nT2xFm2iIFYD5BI3G?node-id=2-114

Макеты не меняют действующие решения по категориям, БД и алгоритмам. Код сайта и production этой операцией не менялись. Следующий шаг — обсуждение экранов с пользователем перед реализацией новых изменений интерфейса.


## Логическая схема ТЗ

По следующему поручению пользователя в тот же файл добавлена отдельная страница «Логическая схема · ТЗ».

[Открыть логическую схему](https://www.figma.com/design/D1SK1nT2xFm2iIFYD5BI3G?node-id=5-47)

Основной поток закреплён слева направо: сбор → классификатор → редактор. Внутри каждого блока шаги идут сверху вниз. Отдельно показаны расширение источников, постоянная память решений и адреса обратных связей. Включены несколько пауков, текст/медиа/происхождение, три проверки повторов, методики категорий, стеки кандидатов и выпуска, наблюдение, отказ с причиной, подготовка/превью/публикация, несколько категорий источника и связи решений с UID/версиями материалов. Основание — «Новости — три блока обработки» и уточнение постоянной памяти в оценке реализации 2026-11-10.

Это целевая логика, не отчёт о полной реализации. Сохранена оговорка о целевом месте подготовки текста после отбора. Схема состоит из редактируемых слоёв; проверена визуально, исправлена высота текста для полного отображения подписей. Код и production не менялись.
