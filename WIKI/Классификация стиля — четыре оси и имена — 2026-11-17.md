# Классификация стиля: четыре оси и многоязычные имена

Пользователь подтвердил принцип: результат исследования ссылается на ID записи справочника. Названия и переводы не служат ключом связи. Пользователь просит проверить существующее деление на макро-эпоху, метод формообразования, направление/школу и атомарные признаки. Данный документ фиксирует аудит и обсуждаемую модель; новых таблиц/полей и миграции классификации пока нет.

## Проверено в рабочей БД

- app.entities: в ветках art_epochs/art_styles найдена только одна запись: ID 1769, Модернизм / Modernism, slug modernizm, тип art_epochs. Записей art_styles — 0.
- Старый public.styles: 14 записей, поля title_ru/title_en, годы и описание; нет признака одного из четырёх уровней. Есть составные названия, например «Интернациональный стиль / модернизм (канон)», «Неомодернизм / минимализм».
- Старый public.features: одна запись «Параметрические элементы», английское название не заполнено. Не является наполненным каталогом атомарных деталей.
- В параметрах исследуемой сущности style_name — текст «Стиль или признак»; style_relation, style_phase, style_zone, style_reason, style_sources также текстовые. Явного разделения четырёх осей и ссылки из строки на запись понятия сейчас нет.
- researchCatalog в intakeResearch.ts выбирает только id/title_ru для опубликованных сущностей art_styles/art_epochs. title_en/title_original/original_language уже имеются у сущностей, но не включены в этот каталог. Неограниченного набора языковых синонимов этот запрос не предоставляет.

## Предложенная модель (обсуждение)

Одна запись понятия с постоянным ID и явной принадлежностью к оси: эпоха/парадигма; метод формообразования; направление/региональная школа; морфологический признак. Не строгое дерево: один метод встречается в разных эпохах и направлениях. На карточке четыре различимых поля/раздела, а не одна колонка «Стиль». Атрибуция связывает сущность, ID понятия, фазу и зону; отдельно содержит отношение (подтверждается/отрицается/спорно/цитата), исходную формулировку, обоснование и источники.

Многоязычные названия и синонимы привязываются к одному ID с языком; совпадение перевода — предложение сопоставления, а не автоматическое доказательство тождества. «НЕ Интернациональный стиль» — отрицательная атрибуция ID Интернационального стиля, не новая запись стиля. Старые ID public.styles/features нельзя использовать как ID app.entities: нужен проверенный перенос и явное соответствие. Неизвестный термин остаётся кандидатом редактору. Источники нужны и для положительных, и для отрицательных атрибуций; отсутствие упоминания не является отрицанием. Примеры Torres de Colón из сообщения пользователя пока являются исследовательскими гипотезами, не массово внесёнными фактами.


## Уточнение от 18.11.2026

Источник атрибуции подключается через существующее цитирование материала обоснования связи и сущность источника. Отдельное поле URL в links не предусматривается. Один источник — одна атрибуционная связь в данном контексте; несколько цитат из него не дают дополнительных голосов. Поддержку цитирования для материалов связей необходимо проверить; при отсутствии расширяется общий механизм.
