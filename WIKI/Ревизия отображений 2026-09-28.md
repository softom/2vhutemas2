## Исправление

Единый HTML-рендер карточки в `pages.ts`, единая загрузка в `publicCard.ts`. Гость получает готовый HTML. При наличии сохранённой сессии проверяются права; редактор и рецензент получают тот же HTML через `GET /api/v1/entities/:key/card`, с `private, no-store`. Гостю черновик возвращает 404 без раскрытия названия или текущего slug. Страница 404 сущности больше не запускает React и не зацикливает переходы.

Каталог, список лекций и кнопка возврата открывают обычную ссылку. React-маршрут остаётся только переходником для старых внутренних вызовов и не рисует карточку. BlockNote работает в редакторе; цитаты и старые таблицы нормализуются при открытии без записи в БД.

Карточка сохраняет все группы показателей, даты, места, связи, текст, изображения, источники и цитирование по запросу. Компактные элементы каталогов и вставки сущностей остаются компактным режимом; это не дубликаты подробной карточки. Медиатека и её форма остаются самостоятельным экраном универсального элемента.

Дополнение пользователя: действие редактирования — карандаш сразу после названия, с доступным именем «Править запись» и подсказкой «Править». Показывается после проверки `edit`/`su`.

## Проверка

План: типы, сборка, smoke (гость и SU на черновике), браузерный маршрут каталог → карточка → редактор → карточка, прямой URL и перезагрузка, четыре текста «О проекте», отсутствие тяжёлых модулей у гостя. Статус выполнения записывается после проверки. Миграций БД нет.

Дополнительно: ссылка редактора использует UID, редактор также разрешает slug через API. Выкладка исключает зависимости, сборку, локальные настройки и кэш типов из архива; ошибка сборки больше не маскируется конвейером grep.

## Дополнение: ревизия меню

Пользователь обнаружил пропущенное дублирование шапки. `pages.ts` содержал отдельный NAV с урезанным набором пунктов и постоянным «Войти», `App.tsx` — другой набор с правами. Это не выход из учётной записи: на присланном снимке карандаш уже доступен SU. Оба набора заменены `api/src/lib/siteHeader.ts`, который формирует меню и для готового HTML, и для React-приложения. `/api/v1/site-header` отдаёт тот же HTML и модель прав; клиент показывает имя и выход, не создавая свой набор пунктов. В обработчике события Supabase запрос сессии отложен до выхода из блокировки авторизации.

Удалён также неиспользуемый экземпляр схемы BlockNote: редактор создаёт собственную схему. Сохранения пользовательских материалов при браузерной проверке не выполняются.

При визуальной сверке обнаружена потеря части адреса в старом серверном формате: он читал несуществующие `address`/`title` вместо `street`/`house`/`unit`. Формат исправлен согласно модели места и проверяется smoke на собственной тестовой записи.
