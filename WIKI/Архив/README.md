Актуальная [схема](../Схема%20данных.md), [API](../API.md), [план](../План%20реализации.md), [главная WIKI](../README.md).

Снимки «до сверки 2026-10-01» сохраняют прежний текст целиком; исправлены только относительные ссылки после переноса. Незакрытые замечания ревизии вынесены в текущий план. Открытые авторские задачи и пользовательская таблица этапов остаются в действующей WIKI.
