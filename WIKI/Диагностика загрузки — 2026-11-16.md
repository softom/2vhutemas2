## Локализация и следующий шаг

Обработчик api/src/routes/entities.ts строит один SQL с read_entities, параметрическими фильтрами, сортировкой, cover_asset и compact_json. Это кандидат для EXPLAIN ANALYZE после получения точных параметров проблемного GET; тяжесть отдельных функций пока гипотеза.

Для вошедшего пользователя publicPage.ts последовательно ожидает site-header → session → card; API предварительно ждёт supabase.auth.getSession(). Это дополнительный возможный источник ожидания, но текущие измерения его причиной не доказали.
