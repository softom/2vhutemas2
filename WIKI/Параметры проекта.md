# Параметры проекта

Действующие технические настройки API берутся из окружения контейнера через [config.ts](../api/src/lib/config.ts). [project.parameters.yaml](../config/project.parameters.yaml) — проект конфигурации со статусами specified/proposed/unresolved; приложение его **не читает**. Полный прежний реестр предложений — [в архиве](Архив/Параметры%20проекта%20—%20до%20сверки%202026-10-01.md). null в проекте не означает отсутствие ограничения.

## Действующие источники

| Настройка | Переменные / значение по умолчанию в коде |
|---|---|
| Порт API | PORT / 8000 |
| Подключение БД | APP_API_DB_HOST / supa_db; PORT / 5432; NAME / postgres; USER / app_api; POOL / 10 (все с префиксом APP_API_DB_) |
| Пароль БД и подпись токена | APP_API_DB_PASSWORD, JWT_SECRET — обязательны; значения только в защищённом окружении |
| CORS | CORS_ORIGINS; default http://localhost:5173 — для разработки, рабочие origin задаёт сервер |
| Страница списка | API_PAGE_SIZE_DEFAULT / 24; API_PAGE_SIZE_MAX / 100 |
| Корень медиахранилища | MEDIA_ROOT / /data |
| Предел файла/пикселей | MEDIA_MAX_BYTES / 1 073 741 824; MEDIA_MAX_PIXELS / 400 000 000 |
| Допустимые MIME | MEDIA_ALLOWED_MIME; default JPEG, PNG, WebP, AVIF, TIFF, HEIC, PDF, MP4; обработка зависит от доступных инструментов |
| Длинная сторона производных | MEDIA_SCREEN_MAX_EDGE / 1600 (до 2026-10-24 — 2560); MEDIA_THUMBNAIL_MAX_EDGE / 400; рецепт MEDIA_RECIPE_VERSION / v2 |
| Качество / версия рецепта | MEDIA_QUALITY / 82; MEDIA_RECIPE_VERSION / v1 |
| Поиск: эмбеддинги (Р-109) | POLZA_API_KEY — без него поиск только по словам; POLZA_BASE_URL / https://api.polza.ai/api/v1; SEARCH_EMBED_MODEL / openai/text-embedding-3-large (смена пересчитывает все векторы); размерность закреплена — 1536 |
| Поиск: индексатор | SEARCH_EMBED_BATCH / 64; SEARCH_INDEX_INTERVAL_MS / 15000 |
| Поиск: ответ ИИ (Р-114) — кому | SEARCH_AI_AUDIENCE / all; допустимо all — всем, registered — вошедшим, editors — правящим, off — выключено |
| Поиск: ответ ИИ — лимиты | SEARCH_AI_DAILY_LIMIT / 50 ответов на человека в сутки (гостю — по суточному псевдониму, su без лимита); SEARCH_AI_DAILY_TOTAL / 1000 — общий потолок сайта в сутки |
| Поиск: ответ ИИ — модель | SEARCH_AI_MODEL / deepseek/deepseek-v4-pro; SEARCH_AI_PASSAGES / 10 кусков в запросе |

Это defaults кода, **не утверждение о текущих значениях серверного .env**. Эффективные публичные лимиты загрузки/списков возвращает GET /capabilities. Конфигурация URL сайта, шаблона, IndexNow — [site.ts](../api/src/lib/site.ts); клиент Supabase настраивается серверным app-web/.env при сборке. Секреты не включаются в Git/WIKI и в открытые ответы API.

Предметные параметры хранятся в parameters/parameter_sets, настройки вида — type_presentations/type_presentation_items. Они не глобальные env-настройки и описаны в [схеме](Схема%20данных.md). Размер, MIME, SHA-256, варианты конкретного файла — media_files. Выравнивание и композиция конкретного блока принадлежат тексту записи, не общему рецепту.

## Открытая конфигурация

Расписание/retention, отдельное место BackUp, шифрование, RPO/RTO и период восстановления пока требуют настройки по [BackUp](BackUp.md). Предложения автосохранения, импорта, Telegram, повтора задач из YAML не объявляют соответствующие функции работающими. Любой перенос настройки в БД требует явного решения; второй конкурирующий источник значений автоматически не заводится.
