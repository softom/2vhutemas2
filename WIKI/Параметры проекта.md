# Параметры проекта

Изменяемые настройки собраны из ТЗ, описания проекта, схемы БД, API и навыка. Проект значений хранится в [project.parameters.yaml](../config/project.parameters.yaml). Приложение пока не читает этот файл.

## Где храним

**Предложение для старта — YAML в репозитории.** Его удобно проверять вместе с кодом, версионировать и использовать в API, медиасервисе и редакторе. Файл содержит значения и их статус: specified — зафиксированное требование, proposed — предложение, unresolved — нужно определить. null не означает отсутствие ограничения и не является рабочим значением. До включения функции её обязательные параметры должны пройти валидацию.

**Таблица БД нужна позже**, если настройки потребуется менять из административного интерфейса без выпуска приложения. Пока второй источник значений не создаём. Возможная будущая таблица `project_settings`: key (PK), value (jsonb), revision, updated_at, updated_by; отдельный журнал изменений. Типы, единицы и допустимые границы определяются схемой конфигурации в коде. Если выберем БД, проведём явный перенос: YAML станет только исходным шаблоном, без неявного смешивания двух источников.

Секреты, токены и пароли не входят в этот файл или публичный API параметров. Пути томов, адреса серверов и прокси остаются конфигурацией окружения и инфраструктурной WIKI.

## Реестр

Точные значения и статус — в YAML, здесь назначение и область применения.

| Группа ключей | Настройка | Где применяется |
|---|---|---|
| media.screen.max_long_edge_px | Предел длинной стороны экранного изображения, px | Генерация screen |
| media.thumbnail.max_long_edge_px | Предел длинной стороны превью, px | Генерация thumbnail |
| media.derivatives.allow_upscale | Разрешено ли увеличение маленького оригинала | Обработка изображения |
| media.*.output_format, media.derivatives.quality | Формат производных и качество кодирования | Рецепт обработки; шкалу качества определить после выбора кодека |
| media.upload.max_bytes, max_pixels, allowed_mime_types | Размер файла, число пикселей и разрешённые форматы | Проверка загрузки и декодирования |
| media.processing.timeout_seconds, max_concurrency | Время и параллелизм обработки | Очередь медиасервиса |
| editor.image.allowed_width_presets, default_width_preset | Доступные ширины и начальная ширина изображения | Композиция BlockNote |
| editor.image.allowed_alignments, default_alignment | Варианты и начальное выравнивание | Редактор и просмотр |
| editor.autosave.debounce_ms | Задержка автосохранения | Редактор черновика |
| theme.content.max_width_px, theme.breakpoints_px | Ширина страницы и границы адаптивного отображения | Тема сайта |
| theme.fonts, spacing_scale, highlight_palette | Шрифты, интервалы и палитра выделения | Общий дизайн |
| articles.references.default_version_mode | Текущая опубликованная или закреплённая версия по умолчанию | Вставка ссылки; конкретный выбор сохраняется в блоке |
| search.language_configs | Языковые конфигурации поиска | Извлечение и индексирование текста |
| api.pagination.default_page_size, max_page_size | Размер страницы по умолчанию и максимум | Списки API |
| imports.max_items_per_batch, max_payload_bytes | Предел числа записей и размера пакета | Проверка импорта |
| automation.retry.max_attempts | Максимум попыток, включая первую | Навык и клиент импорта, только временные ошибки |
| api.idempotency.retention_seconds | Срок хранения результата повторяемой операции | API импорта |
| telegram.link_code.ttl_seconds, max_attempts | Срок и число попыток подтверждения | Сервер привязки аккаунта |
| users.onboarding.default_role_ids | Начальные роли после подтверждения | Онбординг; набор ещё не согласован |
| backup.schedule, retention_days | Расписание и глубина хранения | Резервирование |
| backup.target_rpo_hours, target_rto_hours | Допустимая потеря по времени и целевое время восстановления | План BackUp |
| backup.restore_test_interval_days | Период проверки восстановления | Контроль пригодности копий |

Место резервного хранения задаётся окружением после выбора отдельного хранилища; доступы в YAML не входят. Источники и процесс — [BackUp](BackUp.md). default_role_ids содержит UID ролей, а не их текстовые имена.

Параметры без выбранных значений выявлены по требованиям, но не объявлены уже согласованными. Особенно это относится к загрузке, привязке аккаунтов и выдаче прав.

## Что не является глобальной настройкой

- Фактические width/height файла, checksum и MIME — метаданные конкретного файла в БД.
- Выбранная ширина, выравнивание, кадрирование и медиа конкретной иллюстрации — свойства блока BlockNote. Глобальные настройки задают только доступные варианты и начальное значение.
- Цвет объекта, порядок объектов, координаты в пространстве и выбранная версия ссылки — данные объекта/представления/документа.
- Роли конкретного пользователя — назначения в БД. Необходимость авторизации и обязательное обоснование связи — инварианты, а не выключаемые настройки.
- Три варианта изображения, формат BlockNote и версия схемы данных — архитектурный контракт. Их смена требует изменения реализации, а не произвольного редактирования YAML.
- Четыре этапа реализации — план работ, не feature flags и не настройки доступа.

## Применение изменений

Проверять типы, единицы, диапазоны и совместимость настроек; неизвестный ключ считать ошибкой. API выдаёт только разрешённую клиентскую часть настроек; редактор не получает служебные лимиты привязки и секреты. Проверка ограничения на клиенте не заменяет серверную.

Размеры производных применяются к новым заданиям обработки. Сохранять эффективные значения в `media_files.transform_params` и версию рецепта; существующие файлы не перегенерируются незаметно. Изменение оформления по умолчанию не перезаписывает уже выбранные свойства блоков. Смена поисковой конфигурации требует переиндексации. Изменение начальных ролей не меняет права уже зарегистрированных пользователей задним числом.

Параметры безопасности с null блокируют соответствующую функцию при её включении; они не превращаются в unlimited. Изменение параметров оформляется отдельной проверяемой правкой. До реализации загрузчика YAML — проект спецификации, не действующий конфиг сервера.
