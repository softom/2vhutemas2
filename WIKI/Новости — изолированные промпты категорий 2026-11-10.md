# Новости — изолированные промпты категорий

Пользователь уточнил: уже классифицированная новость должна оцениваться отдельным промптом своей категории; настройки каждой категории оптимизируются отдельно. Во вкладке 2 сначала показывается промпт выбранной категории, затем её новости. Это заменяет промежуточный подход с разделами единого запроса.

Реализованы шесть отдельных шаблонов prompts/categories/*.md. Запрос оценки содержит только шаблон категории, общие правила профиля, профиль этой категории и её редакторские примеры. Другие разделы и неразмеченные общие seed-примеры в оценку не включаются. Совместимые topic/kind сохраняются; category является логическим атрибутом промежуточного JSON, не строковым FK в БД.

При переоценке известная категория берётся из сохранённой оценки (для прежних данных — переходное сопоставление topic/kind/competition); повторная LLM-классификация не нужна. Только материалы без известной категории проходят короткий отдельный запрос классификации без критериев ценности. Пачка оценки состоит из материалов одной категории. Неопределённая категория не превращается в отрицательную редакторскую оценку; материал остаётся без новой оценки и требует разбора. Сохранённые прежние оценки при неполном ответе не удаляются.

Калибровка и её проверочные запросы разделены по категориям; в обучение не включается отложенная выборка. Профили/история калибровки обновляются отдельно; старые общие статистические поправки ранжирования остаются для совместимости и не объявляются шестью независимыми алгоритмами ранжирования. Бенчмарк bench.py — отдельный исторический стенд, не производственный путь.

Вкладка 2: переключатель категорий → открытый шаблон и профиль категории → сохранение/переоценка → полный действующий запрос → новости выбранной категории. Черновики правок сохраняются при переключении вкладок. Сохранение касается только выбранного раздела; API проверяет категорию, размер и placeholders. Вставка заголовка другой категории в поле профиля не изменяет чужой раздел. Переоценка — только непросмотренные новости выбранной категории. Сохранение без переоценки не запускает очистку/пересборку пула.

Существующий полный смешанный шаблон и профиль сохранены как прежние настройки, но общий шаблон не используется производственной оценкой. Представление full_prompt теперь прямо указывает на category_prompts, где находятся реальные запросы. Никакие платные вызовы LLM и массовая переоценка при внедрении не запускаются.

Проверки: 11 Python-тестов, включая изоляцию правил/примеров/материалов, отсутствие повторной классификации, отдельную калибровку, сохранность чужих разделов; TypeScript, Vite; браузер с тестовым API (порядок промпт/новости, фильтр, независимые черновики, ограничение сохранения/переоценки категорией). Выкладка описывается после проверки. Прежние незакоммиченные изменения pool.py/run.py сохраняются отдельно; в pool.py в коммит включены только изменения этой задачи.
