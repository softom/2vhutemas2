# Исправление ввода своей причины

Пользователь сообщил о мигании окон и зависании на 2–3 минуты при выборе «Своя причина». В коде не найден цикл модальных диалогов; прежний элемент — native select с постоянным value="", немедленным сбросом и обновлением состояния всей таблицы. Точное воспроизведение системного зависания пока не подтверждено.

Вместо select введена встроенная форма PositiveReason: варианты причин обычными кнопками, собственная причина в textarea той же строки, явная отправка кнопкой. Черновик хранится локально в компоненте, набор текста не перерисовывает всю таблицу. Открытие формы и ввод ничего не отправляют; пустую причину отправить нельзя; синхронный ref блокирует повторные отправки до завершения запроса. Авторизация, API и хранилище решений сохранены.


Выложено `eff6590`. Проверены TypeScript и Vite локально и на сервере; в Chromium на тестовом API открытие и ввод не отправляют оценку и не открывают диалоги, двойной клик сохранения отправляет ровно один judge с собственной причиной. Ошибок JS нет. Сервер отдаёт страницу (HTTP 200), оба исходника сверены SHA-256 с коммитом. Само системное зависание пользователя не воспроизведено; исправление убирает native popup из этого сценария.
