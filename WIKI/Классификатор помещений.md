# Классификатор помещений

Единый классификатор для площадных программ всех типологий — театр, офис, школа, жильё. Нужен, чтобы сравнивать проекты между собой: доли зон, площадь на человека, долю коммуникаций и инженерии. Программа хранится у записи значением-таблицей «Площадная программа» (0040–0042, [Решения](Решения.md), 2026-10-14). Классификатор — дерево вариантов параметра «Назначение»: в строке выбирается один узел, зона — его корень. Если источник не детальнее зоны или раздела, выбирается сам этот узел.

## Уровень 1 — зона

Одна для всех зданий. Основа — классификатор общественных зданий пользователя; «Пути движения и техника» разведены на три зоны: коммуникации, инженерия, парковка — у них разный смысл в анализе.

| № | Зона | Театр | Офис | Школа | Жильё |
|---|---|---|---|---|---|
| 1 | **Место основной деятельности** | сцена, карманы, арьер, сценическая техника, колосники | рабочие места, open space, переговорные | классы, лаборатории, спортзал | квартиры: жилые комнаты, кухни, прихожие, санузлы |
| 2 | **Места зрителей и слушателей события** | зрительный зал, балконы, ложи | залы собраний, конференц-залы | актовый зал, трибуны | — |
| 3 | **Пользователи вне основной зоны** | вестибюль, фойе, гардероб, кафе, гостевой клуб и лаунж | ресепшен, кафе, лаунж | рекреации, столовая, гардероб | холлы, колясочные |
| 4 | **Исполнители / персонал основной деятельности** | гримёрные, репетиционные | — | учительские, методкабинеты | — |
| 5 | **Производство и склады** | мастерские, разгрузка, склады декораций | архив, склады | кладовые, пищеблок | внеквартирные кладовые, мусорокамеры |
| 6 | **Управление и службы** | администрация, охрана, пресса | администрация, охрана, клининг | администрация, медпункт | управляющая компания, диспетчерская, консьерж |
| 7 | **Другие функции** | музей, выставка, образование; аренда, магазины | торговля на первом этаже | — | коммерция на первом этаже |
| 8 | **Пути движения** | лестницы, коридоры, лифтовые холлы | то же | то же | МОП, лестничные клетки |
| 9 | **Инженерные системы** | по разделам — уровень 2 | | | |
| 10 | **Парковка** | | | | |

**Как читать зоны.**
- Зона 2 — места зрителей или слушателей *события*, а не пользователей вообще. Класс со школьниками — зона 1 (основная деятельность), актовый зал — зона 2.
- Санузел идёт в зону той группы людей, которая им пользуется: зрительские — в зону 3, артистические — в зону 4, служебные — в зону 6, квартирные — в зону 1.
- Ложи — места, с которых смотрят событие, зона 2 («200 мест в ложах» берлинского задания). Гостевой клуб и лаунж — зона 3, отдельным назначением: это не фойе.
- Переговорная событием не является: в офисе это работа, зона 1. В зоне 2 — залы собраний и конференц-залы.

## Уровень 2 — назначение

Типовое помещение внутри зоны: гримёрная индивидуальная или групповая, репетиционный зал, класс, рабочее место… Список пополняется с новыми типологиями.

Для инженерии назначение — по разделам проекта:

| Раздел | Помещения |
|---|---|
| ОВ | венткамеры, ИТП, котельная, холодильная станция, градирни |
| ВК | насосные, водомерный узел, резервуары |
| ЭС / ЭО | трансформаторная, электрощитовые, ДГУ |
| СС | серверные, кроссовые, слаботочные |
| ПБ | пожарные насосные, помещения АУПТ |
| ТХ | только то, что не часть сцены: кинопроекционные, аппаратные звука и света, машинные сценической механики |

Сценическая техника, колосники и рабочие галереи — часть сцены, зона 1: в заданиях сцена с техникой нередко одна строка.

Назначения, понадобившиеся в первых пяти документах: ложи — зона 2; гостевая зона (клуб, лаунж) — зона 3; разгрузка и грузовой путь (разгрузочная, грузовой лифт, склад декораций) — зона 5; пресса и службы порядка (полиция, пожарные, пункт управления) — зона 6; музей, выставка, образование — зона 7. Полный список узлов — варианты параметра «Назначение» (`GET /parameters`, поле `options` с `parent`).

## Свойства всей программы

Документы считают разное, и без этих свойств проценты двух зданий нельзя ставить рядом. Заполняются в той же группе сведений, что и таблица.

| Свойство | Варианты |
|---|---|
| Стадия программы | задание / проект / построено |
| База площади | полезная (НУФ, DIN 277) / общая / помещения программы |
| Пути движения и техника | перечислены строками / заданы коэффициентом / отдельно, сверх полезной / не учтены |
| Коэффициент | число, если коммуникации и техника заданы коэффициентом: 1,6 — общая = полезная × 1,6 |

## Формат строки программы

Одна строка — помещение или группа одинаковых помещений. Таблица в Excel или CSV, колонки в этом порядке:

| Колонка | Что писать | Обязательно |
|---|---|---|
| Зона | одна из 10 зон уровня 1 | да |
| Назначение | типовое помещение уровня 2; для инженерии — раздел и помещение («ОВ — венткамера») | да |
| Помещение | название по источнику | да |
| Тип площади | помещение / открытая / под навесом — трибуны, поле, терраса это площадь, но не помещение, и в итог входят | да |
| Часть здания | зал или корпус, к которому относится помещение: «Большой театр», «корпус Б», «общее» | для зданий из нескольких частей |
| Уровень | этаж: «B1», «1F», «+1», «−2» | желательно |
| № | номер помещения по источнику | если есть |
| Кол-во | сколько таких помещений | если больше одного |
| Людей | расчётное число людей; смысл задаёт зона: зрительские места, рабочие места, ученики, места в гримёрных, проживающие | если известно |
| Площадь, м² | площадь одного помещения | если известна |
| Площадь всего, м² | площадь всех таких помещений, если известна только она | — |
| Основание площади | по документу / по габаритам / оценка / не указана | да |
| Габариты, м | «19,02 × 13,23», если площадь посчитана по ним | — |
| В итог | да / нет — «нет», только если площадь уже учтена в другой строке (двойной счёт). Решает не название помещения: колосники Тайбэя входят в площадь этажей | да |
| Источник | документ и страница: «Технический паспорт GT, стр. 41» | да |
| Примечание | оснащение, оговорки | — |

**Правила:**
- Площадь не выдумывать и не делить пропорционально. Неизвестна — «не указана», строка всё равно нужна: она фиксирует состав.
- Площади этажей — отдельной таблицей (уровень, площадь, источник), не строками программы: этаж — точная площадь по документу, помещения — состав и оценки, их сумма с этажами даёт двойной счёт.
- Пересекающиеся строки — например, трансформация сцены, уже посчитанная в других строках, — вносить с «В итог: нет».

Пример по Тайбэйскому центру исполнительских искусств — `research_notes/Материалы для программы Тайбэйского центра/program-draft.csv` (78 строк в этом формате; последняя колонка «Код назначения» — код узла классификатора для загрузки через API) и `floors-draft.csv` (16 этажей по лицензии). Свойства программы: стадия — построено, база площади — помещения программы, пути движения и техника — не учтены. Площади известны у 16 строк, все по габаритам; там, где источник не детальнее зоны (технические помещения B1), выбрана сама зона.
