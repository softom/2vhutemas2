# Классификатор помещений

Единый классификатор для площадных программ всех типологий — театр, офис, школа, жильё. Нужен, чтобы сравнивать проекты между собой: доли зон, площадь на человека, долю коммуникаций и инженерии. Программа хранится у записи значением-таблицей «Площадная программа» (0040, [Решения](Решения.md), 2026-10-14).

## Уровень 1 — зона

Одна для всех зданий. Основа — классификатор общественных зданий пользователя; «Пути движения и техника» разведены на три зоны: коммуникации, инженерия, парковка — у них разный смысл в анализе.

| № | Зона | Театр | Офис | Школа | Жильё |
|---|---|---|---|---|---|
| 1 | **Место основной деятельности** | сцена, арьер, карманы | рабочие места, open space | классы, лаборатории, спортзал | жилые комнаты |
| 2 | **Места пользователей** | зрительный зал, балконы | переговорные, залы собраний | актовый зал, трибуны | — |
| 3 | **Пользователи вне основной зоны** | вестибюль, фойе, гардероб, кафе | ресепшен, кафе, лаунж | рекреации, столовая, гардероб | холлы, колясочные |
| 4 | **Исполнители / персонал основной деятельности** | гримёрные, репетиционные | — | учительские, методкабинеты | — |
| 5 | **Производство и склады** | мастерские, склады декораций | архив, склады | кладовые, пищеблок | кладовые, кухни |
| 6 | **Управление и службы** | администрация, охрана | администрация, охрана, клининг | администрация, медпункт | санузлы, прихожие квартир |
| 7 | **Другие функции** | аренда, магазины | торговля на первом этаже | — | коммерция на первом этаже |
| 8 | **Пути движения** | лестницы, коридоры, лифтовые холлы | то же | то же | МОП, лестничные клетки |
| 9 | **Инженерные системы** | по разделам — уровень 2 | | | |
| 10 | **Парковка** | | | | |

## Уровень 2 — назначение

Типовое помещение внутри зоны: гримёрная индивидуальная или групповая, репетиционный зал, класс, рабочее место… Список пополняется с новыми типологиями.

Для инженерии назначение — по разделам проекта:

| Раздел | Помещения |
|---|---|
| ОВ | венткамеры, ИТП, котельная, холодильная станция, градирни |
| ВК | насосные, водомерный узел, резервуары |
| ЭС / ЭО | трансформаторная, электрощитовые, ДГУ |
| СС | серверные, кроссовые, слаботочные |
| ПБ | пожарные насосные, помещения АУПТ |
| ТХ | технологическое: сценическая механика, колосники, галереи |

## Формат строки программы

Одна строка — помещение или группа одинаковых помещений. Таблица в Excel или CSV, колонки в этом порядке:

| Колонка | Что писать | Обязательно |
|---|---|---|
| Зона | одна из 10 зон уровня 1 | да |
| Назначение | типовое помещение уровня 2; для инженерии — раздел и помещение («ОВ — венткамера») | да |
| Помещение | название по источнику | да |
| Часть здания | зал или корпус, к которому относится помещение: «Большой театр», «корпус Б», «общее» | для зданий из нескольких частей |
| Уровень | этаж: «B1», «1F», «+1», «−2» | желательно |
| № | номер помещения по источнику | если есть |
| Кол-во | сколько таких помещений | если больше одного |
| Людей | расчётное число людей; смысл задаёт зона: зрительские места, рабочие места, ученики, места в гримёрных, проживающие | если известно |
| Площадь, м² | площадь одного помещения | если известна |
| Площадь всего, м² | площадь всех таких помещений, если известна только она | — |
| Основание площади | по документу / по габаритам / оценка / не указана | да |
| Габариты, м | «19,02 × 13,23», если площадь посчитана по ним | — |
| В итог | да / нет — «нет» для того, что даст двойной счёт: колосники и галереи над сценой, открытые террасы | да |
| Источник | документ и страница: «Технический паспорт GT, стр. 41» | да |
| Примечание | оснащение, оговорки | — |

**Правила:**
- Площадь не выдумывать и не делить пропорционально. Неизвестна — «не указана», строка всё равно нужна: она фиксирует состав.
- Площади этажей — отдельной таблицей (уровень, площадь, источник), не строками программы: этаж — точная площадь по документу, помещения — состав и оценки, их сумма с этажами даёт двойной счёт.
- Пересекающиеся зоны — сцена и её трансформации, колосники — вносить, но с «В итог: нет».

Пример по Тайбэйскому центру исполнительских искусств — `research_notes/Материалы для программы Тайбэйского центра/program-draft.csv` (78 строк, ещё по прежним разделам) и `floors-draft.csv` (16 этажей по лицензии).

## Ещё не решено

1. Десять зон уровня 1 — или восемь исходных с объединённой «Пути движения и техника».
2. Разделы инженерии: ОВ, ВК, ЭС/ЭО, СС, ПБ, ТХ — достаточно ли.
3. Отметка у назначения, входит ли оно в полезную и расчётную площадь по СП 118 (жильё — СП 54), — сразу или позже.

До решения в базе действует прежний список «Раздел» площадной программы (0040); перевод на зону и назначение — отдельной миграцией.
