# Запрет публикации каталога роботом новостей — 11.11.2026

Пользователь обнаружил опубликованный музей Powerhouse Parramatta и связи с Moreau Kusunoki / Genton без утверждения в стеке. Подтверждено по production .state/prepared/powerhouse-parramatta-opening.json: объект 2815, авторы 2816/2817, связи 1692/1693; черновики 10.11.2026 23:48:38 МСК, публикация 11.11.2026 09:30:18 МСК вместе с новостью 2818.

Причина: прежний publish.link_entities создавал проект, авторов и связи; publish.publish публиковал их без проверки стека. Новая передача в стек не отключила этот путь. Уверенное утверждение исполнителя о невозможности обхода было ошибочным.

Новая инструкция пользователя и утверждённый сценарий эскиза заменяют прежнее поведение Р-106: публикатор новостей создаёт и публикует только запись типа news. Извлечение/создание авторов и объектов из публикатора удалено; прежние списки entities.created/links больше не публикуются. Материалы направляются в стек сущностей; публикация каталога и связей — только после редакторского утверждения.

Существующие записи, источники, версии и связи не удаляются и не изменяются этим исправлением. Отдельная ревизия ранее автоматически опубликованных записей остаётся необходимой. Исправление не снимает уже опубликованный музей с сайта.

Регрессионная проверка: новая новость создаёт только news, LLM извлечения не вызывается, старое задание с неподтверждёнными объектами и связями публикует только новость, прежние материалы сохраняются. API и схема БД не меняются.
