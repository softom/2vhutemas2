# Новости — сохранение и немедленная публикация

12.11.2026. После исправления сохранения пользователь заметил, что «Сохранить и опубликовать» выпустила новость до слота 18:00. Причина: штатная кнопка редактора вызывает публикацию сразу, а расписанием управляет робот отдельно.

Решение: «Сохранить версию» по-прежнему сохраняет только рабочую версию. Для типа «Новость» и его потомков второе действие называется «Опубликовать сейчас…». Первое нажатие ничего не сохраняет и не публикует: на странице открывается пояснение об обходе назначенного времени и две кнопки — подтвердить немедленную публикацию или отменить. Системные confirm/prompt не используются. Отправка на рассмотрение для редакторов без права публикации сохранена.

Очередь и автоматический выпуск не меняются. Публикатор берёт текущую версию записи. Ручное сохранение не добавляет новость в очередь, что пояснено в UI. Уже опубликованную новость 3059 не снимаем с публикации — пользователь принял её текущий выпуск.

План: сборка Web, проверка обеих групп действий и отмены в браузере без изменения новости, выкладка с копией предыдущего фронтенда. API и схема БД не меняются.

Дополнение 12.11.2026: изменение включено в общий коммит корзины. Проверки TypeScript и сборки прошли; браузерная проверка кнопок не выполнена из-за ограничения инструмента для Яндекс Браузера.
