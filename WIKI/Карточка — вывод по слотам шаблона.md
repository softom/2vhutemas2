# Карточка сущности · вывод по слотам

22 ноября 2026 года принято правило: при наличии действующего шаблона карточки каждый содержательный блок выводится по слоту этого шаблона. Включая МЕНЮ, Подвал, заголовок с метаданными, переходы между новостями, новости за день и редакторские материалы. Материалы требуют также действующих прав. Страница без назначенного и унаследованного макета использует прежний вывод. Правило относится к карточкам, не меняет списки разделов.

Для редактора добавлены три реализации: Заголовок карточки (card_title), Листать новости (news_navigation), Новости за день (news_same_day). Миграция 0078 регистрирует их в каталоге. Существующие шаблоны не редактируются этой миграцией.

На изолированной копии новость UID 2818 получила по очереди шаблон с единственным текстовым слотом и шаблон с меню, заголовком, текстом, навигацией и подвалом. На публичном адресе оба ответа HTTP 200. Проверено отсутствие незаданных блоков в гостевом HTML и ответе API редактора, включая редакторские материалы. Восстановлено прежнее назначение копии.

Перед рабочей выкладкой требуется решение о составе действующих шаблонов. В частности, прежние шаблоны создавались до появления отдельного виджета заголовка. Переход без подготовки меняет также доступность ссылки «Править» в заголовке.
