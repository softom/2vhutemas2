# Шрифты для чертежей DXF

Roboto и Noto Sans TC — SIL Open Font License 1.1, из репозитория google/fonts (2026-10-15). Нужны просмотрщику чертежей (`web/src/drawing/viewer.ts`) для надписей: латиница и кириллица — Roboto, традиционный китайский — Noto Sans TC. Noto Sans TC подгружается, только если на чертеже есть иероглифы.
